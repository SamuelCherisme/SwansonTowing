## 🚀 Deployment

### Hosted on Netlify

The site is deployed and hosted on Netlify with continuous deployment.

**Deployment Commands:**
```bash
# Install Netlify CLI
npm install -g netlify-cli

# Login to Netlify
netlify login

# Deploy to production
netlify deploy --prod --dir .
```

**Site Details:**
- **Production URL:** https://swansontowing.netlify.app
- **Admin Dashboard:** https://app.netlify.com/projects/swansontowing
